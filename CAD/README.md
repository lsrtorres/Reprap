# CAD

Modelos do projeto exportados do Fusion 360.

- Raiz: montagens e peças do projeto (`.f3d` com histórico paramétrico + `.step` neutro)
- `componentes/`: STEPs de componentes comprados/padrão (NEMA17, perfis, trilhos MGN, polias, eletrônica) usados como referência na montagem

Convenção de nomes: `NN-nome-da-peca_vX.step` (ex.: `10-quadro-base_v1.step`). O `.f3d` correspondente acompanha a mesma numeração.
